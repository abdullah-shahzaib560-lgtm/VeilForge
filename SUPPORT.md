# Support

## Getting Help

VeilForge is currently in early design stage.

### Ways to Get Support

1. **GitHub Issues**  
   Best place for bug reports and feature requests.

2. **GitHub Discussions** (will be enabled later)  
   For general questions and ideas.

3. **Documentation**  
   Check the README and documents in the `docs/` folder.

## Response Time

As this is an early-stage project maintained in free time, response times may vary.

## Commercial Support

In the future, commercial support and enterprise features may be offered under the open-core model.

## Security Issues

Please do **not** report security vulnerabilities through public issues.  
See [SECURITY.md](SECURITY.md) for the proper process.
