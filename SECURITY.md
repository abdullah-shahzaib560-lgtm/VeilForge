# Security Policy

## Supported Versions

| Version     | Supported          |
|-------------|--------------------|
| 0.1.0-dev   | Yes (development)  |

## Reporting a Vulnerability

If you discover a security vulnerability in AegisAgent, please report it responsibly.

**Do not** create public GitHub issues for security vulnerabilities.

Contact the maintainers privately once the public repository and contact method are available.

## Responsible Use

AegisAgent is intended **only** for authorized security testing, research, and education.

Unauthorized testing of systems without explicit written permission is strictly prohibited.
