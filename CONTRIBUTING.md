# Contributing to AegisAgent

Thank you for your interest in contributing to AegisAgent!

This project is currently in early design / concept stage. We welcome feedback, ideas, and contributions.

## How to Contribute

### 1. Reporting Issues
- Use GitHub Issues to report bugs or suggest features
- Please check existing issues before opening a new one
- Provide clear description and steps to reproduce (for bugs)

### 2. Suggesting Features
- Open an issue with the label `enhancement`
- Explain the use case and why it would be valuable

### 3. Code Contributions
Once the project has a more complete foundation, we will accept pull requests.

For now:
- Fork the repository
- Create a new branch
- Make your changes
- Open a Pull Request with a clear description

### Areas We Especially Welcome Help
- New attack probes and techniques
- Connectors for agent frameworks (LangChain, CrewAI, AutoGen, etc.)
- Detection and scoring improvements
- Privacy / proxy related features
- Documentation and examples
- Testing

## Development Setup (Coming Soon)

## Code Style
- Follow PEP 8
- Use `black` and `ruff` for formatting and linting
- Write clear commit messages

## Ethical Guidelines
All contributions must respect the project's ethical use policy.
AegisAgent is intended only for authorized security testing, research, and education.

## Questions?
Open an issue or start a discussion.
